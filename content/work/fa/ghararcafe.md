# کافه قرار

**منوی آنلاین اختصاصی کافه قرار، همراه با پنل مدیریت برای مدیریت منو و محتوای کافه.**

این پروژه برای خود کافه قرار طراحی و توسعه شد؛ با این هدف که منوی کافه از یک فایل PDF یا منوی ثابت، به یک سیستم آنلاین و قابل‌مدیریت تبدیل شود.

![رابط کاربری دسکتاپ منوی آنلاین کافه قرار](/images/work/ghararcafe/desktop.png)

## مسئله

منوی یک کافه محتوایی ثابت نیست.

قیمت‌ها تغییر می‌کنند، آیتم‌های جدید اضافه می‌شوند، بعضی موارد از منو حذف می‌شوند و توضیحات یا ترکیبات محصولات ممکن است تغییر کند. بنابراین یک منوی آنلاین زمانی واقعاً کاربردی است که صاحب کافه بتواند بدون وابستگی به توسعه‌دهنده، محتوای آن را مدیریت کند.

در این پروژه به‌جای ساخت یک صفحه‌ی ساده‌ی معرفی، یک **پنل مدیریت اختصاصی** برای کافه طراحی شد تا مدیریت منو از خود وب‌سایت جدا باشد.

## راه‌حل

سیستم از دو بخش اصلی تشکیل شده است:

### منوی آنلاین

بخش عمومی سایت برای مشتریان کافه طراحی شده و شامل:

* دسته‌بندی آیتم‌ها
* جست‌وجوی سریع در منو
* نمایش قیمت
* توضیحات و ترکیبات
* تصاویر آیتم‌ها
* طراحی واکنش‌گرا برای موبایل
* Dark Mode
* رابط مناسب برای استفاده در محیط کافه

### پنل مدیریت

بخش مدیریتی سیستم برای خود مجموعه ساخته شده تا مدیریت محتوا بدون نیاز به تغییر مستقیم کد انجام شود.

مدیر کافه می‌تواند آیتم‌های منو، دسته‌بندی‌ها، قیمت‌ها، توضیحات و تصاویر را مدیریت کند.

به این ترتیب، وب‌سایت یک خروجی ثابت نیست؛ بلکه یک سیستم محتوایی قابل‌مدیریت است.

## تکنولوژی

* **Backend:** Django
* **Frontend:** HTML / Tailwind CSS
* **Database:** PostgreSQL
* **Admin:** پنل مدیریت اختصاصی مبتنی بر Django
* **Responsive:** Mobile-first

## طراحی

تمرکز طراحی روی استفاده‌ی سریع و بدون اصطکاک در موبایل بوده است؛ چون بخش اصلی استفاده از منوی کافه، روی تلفن همراه مشتری اتفاق می‌افتد.

در کنار نمایش ساده‌ی آیتم‌ها، دسته‌بندی و جست‌وجو کمک می‌کنند مشتری بدون اسکرول طولانی به گزینه‌ی موردنظرش برسد.

## نتیجه

کافه قرار حالا یک منوی آنلاین مستقل دارد که محتوای آن توسط خود مجموعه قابل مدیریت است.

این پروژه نمونه‌ای از رویکرد من به پروژه‌های واقعی است: به‌جای ساخت صرفاً یک رابط کاربری، مسئله‌ی اصلی کسب‌وکار و نحوه‌ی استفاده‌ی واقعی از سیستم را در طراحی در نظر می‌گیرم.

**نوع پروژه:** Custom Web Application
**حوزه:** Hospitality / Digital Menu
**تکنولوژی:** Django · Tailwind CSS
