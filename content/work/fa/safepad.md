## کاری که انجام می‌دهد

یک مدیر یادداشت که در ترمینال اجرا می‌شود. یادداشت‌ها را می‌شود اضافه کرد، خواند، ویرایش کرد، حذف کرد و با کلمه‌ی کلیدی جست‌وجو کرد. همه‌چیز روی همان سیستم می‌ماند و هیچ فضای ابری در کار نیست.

## روش کار

هر یادداشت با رمزنگاری متقارن Fernet از پکیج `cryptography` و با کلیدی که از رمز عبور کاربر ساخته می‌شود رمز می‌شود. رابط ترمینال با Rich ساخته شده است.

```bash
pip install cryptography rich
python main.py
```
