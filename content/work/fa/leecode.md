## کاری که انجام می‌دهد

LeeCode یک پنل انتخاب رنگ به Visual Studio Code اضافه می‌کند. از Command Palette با دستور `Open Color Picker` باز می‌شود، رنگ را با اسلایدرهای قرمز، سبز و آبی می‌سازد و مقدار hex آن را نشان می‌دهد.
