# Gharar Cafe

**A custom digital menu for Gharar Cafe, built with a dedicated management panel for managing the cafe's menu and content.**

This project was developed specifically for Gharar Cafe, with the goal of turning the cafe's menu from a static document into an online, maintainable system.

![Gharar Cafe online menu desktop interface](/images/work/ghararcafe/desktop.png)

## The Problem

A cafe menu is not static content.

Prices change, new items are introduced, some products are removed, and descriptions or ingredients may need to be updated regularly. An online menu becomes much more useful when the cafe can manage its own content without depending on a developer for every small change.

Instead of building a simple static page, the project was designed as a **custom content management system** with a dedicated management panel for the cafe.

## The Solution

The system consists of two main parts:

### Online Menu

The public-facing menu is designed primarily for customers using their phones and includes:

* Menu categories
* Fast item search
* Pricing
* Ingredients and descriptions
* Item images
* Responsive mobile-first layout
* Dark Mode
* A cafe-friendly browsing experience

### Management Panel

A dedicated admin interface allows the cafe team to manage the menu without directly modifying the website's code.

Administrators can manage menu items, categories, prices, descriptions, and images from the management panel.

This makes the website more than a static digital menu: it is a maintainable content system operated by the business itself.

## Technology

* **Backend:** Django
* **Frontend:** HTML / Tailwind CSS
* **Database:** PostgreSQL
* **Admin:** Custom management panel built on Django
* **Responsive:** Mobile-first

## Design

The interface was designed around quick, low-friction use on mobile devices, since customers primarily access the menu from their phones while at the cafe.

Categories and search make it possible to navigate a potentially large menu without relying on long, uninterrupted scrolling.

## Result

Gharar Cafe now has an independent digital menu with a management system that allows the cafe team to keep its content up to date.

The project reflects an approach I use in real-world software work: rather than treating a website as only a visual interface, I consider the business workflow behind it and how the system will actually be used and maintained.
