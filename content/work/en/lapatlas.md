## Concept

LAPATLAS is an interactive 3D atlas designed to explore the internal structure of a laptop. Instead of viewing a laptop as a single object, the project allows users to separate and examine its individual components.

Components such as the motherboard, CPU, GPU, RAM, NVMe storage, battery, Wi-Fi module, cooling system, and display are represented as interactive 3D models. Users can select each component, zoom in, and rotate the model to explore it from different angles.

## Goal

The main goal of LAPATLAS was to create an educational and interactive experience for understanding laptop hardware — somewhere between a traditional 2D diagram and physically opening a device.

## Development

The project was developed with the assistance of AI tools. The focus was not simply on building a website using AI, but on exploring how intelligent tools can reduce the gap between a unique idea and a real implementation.

## Result

LAPATLAS demonstrates how interactive design, 3D models, and AI-assisted development can be combined to create new educational experiences on the web.
